Privacy Policy

Effective Date: October 17, 2026

1. Commitment to Offline-First Data Sovereignty

The Nihongo Syntax Matrix operates on an offline-first architectural model. All morphological analysis, verb conjugation generation, kana matrix mapping, and date grammar calculations execute locally within the client browser runtime using pure ECMAScript.

2. Data Collection and Transmission

This application does not collect, transmit, sell, or analyze personal user data. Specifically:

  • No external network requests or remote API calls are executed during operation.
  • No analytics scripts, tracking pixels, or third-party advertising libraries are loaded.
  • User input strings (verbs, calendar dates) remain in volatile client memory and are never transmitted to any external server.

3. Local Storage Utilization

The application utilizes the browser's native localStorage API strictly to preserve user display preferences across sessions:

  • nsm_theme: Stores color scheme state (light or dark mode).
  • nsm_lang: Stores user interface language preference (English or Japanese).

These values can be cleared at any time through standard browser configuration.

4. Contact & Academic Inquiries

For questions regarding pedagogical methodology or computational linguistic models employed in this matrix, contact the project maintainer via the institutional repository.
